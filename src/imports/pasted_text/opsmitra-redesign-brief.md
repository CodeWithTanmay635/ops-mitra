Redesign the existing OpsMitra interface with a much cleaner, more premium, minimal visual direction.

IMPORTANT:
Do NOT redesign the product into a futuristic AI interface.
Do NOT add a colored top margin, colored top banner, glowing AI effects, gradients, robots, neural-network graphics, chat bubbles, or “AI futuristic” visuals.

Keep the existing soft skeuomorphic / neumorphic visual language, but make it subtle and sophisticated.

The visual goal is:

“Premium modern fintech software with subtle physical depth.”

NOT:

“Futuristic AI dashboard.”

--------------------------------
LAYOUT
--------------------------------

Remove the colored strip / colored margin at the very top of the application completely.

The application should sit naturally on a clean warm-neutral canvas.

Use a consistent content grid with generous whitespace.

Avoid unnecessary containers around containers.

Do not make every section look like a floating card.

Use hierarchy through:
- spacing
- typography
- subtle elevation
- alignment
- surface contrast

rather than excessive borders and shadows.

--------------------------------
SKEUOMORPHISM
--------------------------------

Use restrained soft skeuomorphism.

Cards should have:
- very subtle outer shadow
- extremely subtle inner highlight
- soft rounded corners
- clean flat surfaces
- minimal depth

Controls can use slightly stronger recessed/raised effects.

Do NOT use exaggerated neumorphic shadows.

Nothing should look inflated or like a plastic toy.

The interface should feel tactile but professional.

--------------------------------
COLOR
--------------------------------

Keep the warm off-white / light neutral background.

Use a restrained primary accent.

Primary accent:
muted orange / amber

Supporting colors:
- dark charcoal / navy for text
- muted green for positive financial states
- muted red/coral only for genuine risk
- soft gray for secondary information

Do not use bright saturated colors.

Do not use gradients.

Do not use glowing effects.

Do not use large colored backgrounds behind sections.

Color should communicate meaning, not decoration.

--------------------------------
TYPOGRAPHY
--------------------------------

Use a highly readable modern sans-serif.

Create strong typography hierarchy.

Large:
Page title and important financial numbers.

Medium:
Section headings.

Small:
Supporting information and metadata.

Use font weight carefully.

Avoid excessive bold text.

Give numbers enough breathing room.

--------------------------------
DASHBOARD
--------------------------------

Keep the existing dashboard structure but simplify it.

The primary hierarchy should be:

1. Greeting / page title
2. Important business status
3. Key financial metrics
4. What needs attention
5. Financial trends
6. Supporting information

The “What Needs Attention” section should feel like a normal premium product component, not an AI command center.

Use simple language such as:

“What needs attention”

rather than:

“OpsMitra AI Decision Engine”

Avoid constantly mentioning AI.

The intelligence should be visible through the quality of the information, not through AI branding.

--------------------------------
AI RECOMMENDATIONS
--------------------------------

Keep AI recommendations subtle.

Example:

“What needs attention”

Recover ₹1.4L from Mehta Wholesale

43 days overdue

Normal payment cycle: 18 days

Recommended action
Contact customer today

[View details]

The recommendation should look like a polished financial insight card.

Do NOT add:
- AI avatars
- glowing borders
- robot icons
- animated brain graphics
- futuristic labels
- “AI POWERED” everywhere

OpsMitra should feel intelligent without constantly announcing that it is intelligent.

--------------------------------
FINANCIAL CARDS
--------------------------------

Make financial cards extremely clean.

Example:

Cash at risk
₹2.8L
+18% from last month

Receivables
₹7.4L
₹1.9L overdue

Sales
₹12.6L
+8.4%

Priority actions
6
2 require attention

Use subtle depth and spacing.

Do not make each KPI card visually loud.

--------------------------------
CHARTS
--------------------------------

Simplify charts.

Charts should communicate one idea immediately.

Avoid excessive gridlines, legends, labels, gradients, or decorative elements.

Use thin lines, restrained fills, and minimal annotations.

The chart should support the decision rather than become the centerpiece.

--------------------------------
SIDEBAR
--------------------------------

Keep the sidebar extremely clean.

Use:

OpsMitra

Overview
Receivables
Customers
Insights
Data sources
Settings

The active navigation item should use a subtle elevated/recessed treatment.

Avoid large colored active backgrounds.

Use small visual indicators rather than oversized icons.

--------------------------------
MICRO-INTERACTIONS
--------------------------------

Use extremely subtle interaction design.

Cards:
small elevation change on hover.

Buttons:
small press/recess effect.

Navigation:
smooth active-state transition.

Charts:
gentle entrance animation.

Numbers:
subtle count-up animation.

No bouncing.

No glowing.

No dramatic movement.

No large page transitions.

The animation should be felt rather than noticed.

--------------------------------
OVERALL RESULT
--------------------------------

The final interface should feel:

Clean
Premium
Calm
Financial
Trustworthy
Modern
Human
Tactile

Reference the visual quality of high-end fintech SaaS products, but do NOT copy any specific company's interface.

The user should look at the screen and think:

“This is a serious financial product.”

Not:

“This is an AI demo.”

The interface should have visual restraint.

When in doubt, REMOVE something rather than adding another card, color, icon, border, or effect.
